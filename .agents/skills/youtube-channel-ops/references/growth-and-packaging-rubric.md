# Growth and packaging rubric

This reference absorbs the useful channel-growth parts from the `youtube-upload` skill's `youtube-best-practices.md` for analysis use. Use it when turning metrics into concrete video decisions.

## Small-channel metric priorities

For Beomsu's current channel size, prioritize:

1. **Retention / average view percentage** — whether the content keeps the promise.
2. **CTR / impressions** — whether packaging earns the click; exact values require Studio export.
3. **Watch time** — absolute algorithmic signal, especially for evergreen search videos.
4. **Subscriber gain** — whether the topic converts casual viewers into audience.
5. **Comment quality** — whether viewers ask questions or express intent.

## Retention benchmarks

Use as rough targets, not rigid pass/fail rules:

- 1-3 min: 60%+ good, 75%+ excellent
- 5-10 min: 45%+ good, 60%+ excellent
- 10-20 min: 40%+ good, 55%+ excellent

If average view percentage is under 10% for a long-form video, inspect the opening promise, first visual proof, pacing, and title/thumbnail mismatch.

## Hook and structure checklist

For each underperforming video, check:

- Does the hook deliver the thumbnail/title promise within 15 seconds?
- Is the strongest outcome shown in the first 30 seconds?
- Is there a visible pacing change every 20-30 seconds?
- Is the CTA placed before the observed average view duration?
- Does the intro explain a concrete problem/result rather than the creator's process diary?

Preferred structure for Hermes/AI-agent videos:

1. Result first: show the agent/workflow doing the thing.
2. Problem: name the pain in one sentence.
3. Minimal setup/context.
4. Walkthrough.
5. Lesson + how viewer can try a smaller version.

## Description SEO

For search-oriented videos, description should include:

- first 2-3 lines with primary keyword in the first 25 words
- 200+ characters of natural keyword-rich prose
- timestamp chapters with meaningful labels
- related links/playlists/repos
- 3-5 hashtags at the end, not the first lines

Long-tail specificity beats broad topics. Example: `Obsidian daily notes for developers` is better than `productivity`.

## Thumbnail and title

Use exact CTR only when Studio export provides it. Otherwise treat packaging conclusions as hypotheses.

Strong thumbnail/title principles:

- one idea, maximum 3 visual elements
- 0-4 thumbnail words
- high contrast and consistent brand style
- face/emotion when appropriate
- title carries the searchable problem; thumbnail carries the emotional hook

## Tech/developer niche rules

- Project-based > concept-based.
- Concrete artifact/demo > abstract mental model.
- Screen recordings need large font, zoom on CLI, and narrated window switches.
- For tutorials, 8-15 minutes is often a good target, but only if pacing supports it.
- For 0-1K subscribers, niche focus matters more than broad variety.

## Multiplicative growth checklist

The 15 factors below multiply; one zero can kill the video:

1. title/thumbnail hook
2. opening intro
3. conclusion → evidence → example structure
4. audio quality
5. editing clarity/pacing
6. consistent persona
7. category focus
8. style uniformity
9. tool/topic selection
10. honest limitation / likability
11. relatable specific situation
12. usefulness
13. trend timing
14. narrative: goal → obstacle → choice → result → lesson
15. external traffic/community
